# Resume Examples

以下示例全部为**完全虚构数据**，只用于说明信息密度、Evidence 表达、能力分组、内容取舍和不同岗位的表达差异。

不得：

- 将示例人物信息复制到真实简历；
- 将示例数字当作用户数据；
- 将示例技术栈、公司、学校或项目自动加入候选人档案；
- 要求所有简历复制相同章节、顺序或句式；
- 因为示例写法更“漂亮”而覆盖用户事实边界。

示例不是模板答案。真正生成时必须从当前 JD、Candidate Evidence 和 Positioning 决定内容。

# 使用这些示例的方法

需要参考示例时，Agent 只提取原则：

- 什么情况下应该使用 Capability-first、Keyword-dense 或 Minimal；
- 如何让技能区和经历形成证据对应；
- 如何在没有数字时依然写出有价值的成果；
- 如何根据岗位动态改变能力簇和模块顺序。

不得提取：

- 示例人物信息；
- 示例公司 / 学校 / 项目名；
- 示例中的具体数字；
- 固定句式；
- 固定模块顺序。
